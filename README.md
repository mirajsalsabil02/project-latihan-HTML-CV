# Project Latihan HTML - Curriculum Vitae (CV)

Repositori ini berisi proyek latihan pembuatan **Curriculum Vitae (CV)** sederhana menggunakan struktur dasar **HTML**. Proyek ini dibuat sebagai bagian dari proses belajar dan eksplorasi dasar-dasar pengembangan web (*web development*).

## Fitur & Komponen
Halaman CV ini mencakup beberapa elemen dasar dalam HTML, antara lain:
* **Identitas & Informasi Kontak:** Nama, tautan profesional, dan info kontak.
* **Tentang Saya (*About Me*):** Ringkasan singkat profil pribadi.
* **Riwayat Pendidikan (*Education*):** Informasi latar belakang pendidikan.
* **Pengalaman & Keterampilan (*Skills & Experience*):** Daftar keahlian teknis maupun pengalaman yang dimiliki.
